# No code: ChatGPT / Claude / Gemini

1. Open your existing account and a new chat.
2. Open instructions.md as text and paste it into the chat. Add materials.md and task.txt, by pasting or attaching as supported.
3. If project instructions are available, save them there; exact names depend on application and account.
4. Run tests.md and save your result.

This is a portable assistant starter. It becomes a tool-using agent only when actual tools and tool-choice behaviour are configured. Tools do not come with the text. Do not enable email writes or publishing. Pair up if you have no account.
