# Bez kódu: ChatGPT / Claude / Gemini

## Začněte zde: vytvoření → nastavení → běh → test

1. Upravte brief.md (obsahuje vyplněný fiktivní příklad), nebo použijte brief-template.md.
2. Vložte prompt z create-agent.md do svého nástroje. Přiložte brief.md, instructions.md a materials.md; bez příloh vložte jejich obsah. Samotný odkaz na soubor nestačí.
3. AI připraví nebo upraví agenta. Zkontrolujte výsledek, nastavte skutečné nástroje a oprávnění. Vytvořený text sám agenta nenainstaluje.
4. Pro první běh použijte task.txt, poté tests.md. Uložte skutečný výstup.

## Ve vlastní aplikaci

Otevřete nový chat ve svém existujícím účtu a použijte postup výše. Výsledné instrukce můžete uložit do projektu nebo jiného podporovaného místa. Ověřte, že má aplikace nástroj pro čtení podkladů, výpočet či tvorbu souboru podle vašeho cíle. V běhu sledujte skutečné nástroje. Samotný text přístup ani schopnosti nepřidává. Pokud nástroje nemáte, vytvořili jste asistenta; pro agentní pokus se spojte do dvojice. Nepovolujte odesílání nebo publikování.

## Jeden soubor pro první pokus

Pro vyplněný fiktivní příklad stačí otevřít start-here.txt a vložit celý obsah do nového chatu. Soubor už obsahuje tvorbu, brief, instrukce a podklady. Pro vlastní nápad je upravte; nic se nenainstaluje jen zkopírováním textu. Po nastavení spusťte task.txt.
