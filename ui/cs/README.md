# Bez kódu: ChatGPT / Claude / Gemini

1. Otevřete svůj existující účet a nový chat.
2. Otevřete instructions.md jako text; zkopírujte obsah do chatu. Přidejte materials.md a task.txt (vložením textu nebo souboru, podle možností aplikace).
3. Pokud máte k dispozici projektové instrukce, uložte je tam; přesné názvy závisí na aplikaci a účtu.
4. Proveďte tests.md a uložte si výsledek.

Toto je přenosný základ asistenta. Agentem s nástroji se stane až s reálnými nástroji a rozhodováním o jejich použití. Nástroje nejsou součástí samotného textu. Nezapínejte zápis do pošty nebo publikování. Bez účtu pracujte ve dvojici.
