# Markdown: Codex / Claude Code

1. Use this folder as a standalone project. You need installed, authenticated Codex or Claude Code.
2. Codex reads AGENTS.md; Claude Code reads CLAUDE.md. They refer to brief.md and materials.md; edit those files.
3. Open the folder in your app and enter task.txt. Ask which instructions were loaded.
4. Restrict permissions in the host application; a text file is not a security boundary. Do not automatically allow all commands.
5. Run tests.md and review the output.

AGENTS.md and CLAUDE.md are project instructions, not an automatically installed skill. An actual skill has SKILL.md and a product-supported installation location.
